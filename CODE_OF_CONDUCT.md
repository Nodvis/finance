# Code of Conduct

Nodvis Finance is a community project. Participants are expected to be respectful, constructive and patient, and to focus criticism on ideas and code rather than people.

Harassment, discrimination, doxxing, threats, sexualized conduct and deliberate disruption are not welcome. Maintainers may remove content or restrict participation when necessary to keep the project safe.

Report conduct concerns privately through the security contact described in `SECURITY.md`.
