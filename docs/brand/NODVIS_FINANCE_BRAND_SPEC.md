# Nodvis Finance — final centered v2

## Co zostało naprawione
Poprzedni symbol miał ogromny przezroczysty obszar nad właściwym znakiem.
To powodowało fałszywe centrowanie.

W tej paczce:
- symbol jest wycięty z zatwierdzonego stacked logo po realnych widocznych pikselach,
- canvas symbolu jest ciasny — bez setek pikseli pustej przestrzeni,
- ikony są centrowane geometrycznie: identyczny margines góra/dół oraz lewo/prawo,
- główna ikona używa większego symbolu: 900 px szerokości na canvasie 1024 px,
- nie ma wadliwych `nodvis-symbol-1024/2048/4096`,
- nie ma SVG.
