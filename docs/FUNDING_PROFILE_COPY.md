# Nodvis support profile copy

## Short bio

Building Nodvis: privacy-respecting open-source tools, starting with Nodvis Finance for self-hosted household finances and Nodvis Recall for a future knowledge workflow.

## Long description

Nodvis is an independent umbrella for practical, privacy-respecting software. Nodvis Finance helps households understand available cash, upcoming obligations, debt, transactions and forecasts without sending financial data to a third-party service by default. Nodvis Recall is a separate product in development.

Support helps fund maintenance, security work, documentation, infrastructure and future open-source Nodvis products. Core self-hosted Finance functionality remains available under AGPL-3.0-only; support does not buy access to essential financial features.

## Why support Nodvis

Small recurring support makes it possible to spend time on careful financial correctness, privacy, accessible UX and releases that ordinary self-hosters can actually operate.

## Suggested supporter levels

- **Backer** — helps cover project maintenance and hosting.
- **Builder** — supports security, documentation and release work.
- **Nodvis patron** — supports longer-term open-source product development.

These are public support acknowledgements, not promises of private features, priority bug fixes or release dates.
